# PROJECT TYCOON

A browser-based, single-player project-management campaign. No build step, backend, or account is required.

## Play locally

Open `index.html` in a modern browser. Campaign saves use that browser's local storage on that device.

## Publish as a static site

Upload the contents of this folder to a static web host. The entry page is `index.html`; no server-side settings are needed. For GitHub Pages, add these files to a repository and enable Pages for the chosen branch and folder. For Netlify, deploy this folder as a static site.

The game has no server or shared player accounts. A player's saved campaign remains in their own browser and does not sync between devices.
